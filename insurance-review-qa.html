팀 공유 코드

아래 코드를 팀원에게 알려주세요. 팀원이 같은 코드로 접속하면 같은 데이터를 함께 사용할 수 있습니다.

사용 방법
1
로그인 — 상단 로그인 버튼 클릭 → 이름과 팀 공용 비밀번호 입력
2
코드 공유 — 팀 공유 탭에서 자동 생성된 코드를 복사해 팀원에게 전달
3
팀원 참여 — 팀원이 로그인 후 "다른 팀 코드로 참여하기"에 코드 입력
4
자동 공유 — 이후 모든 등록·수정이 팀 내 자동 공유됩니다
파일로 공유하기
1
현황 탭 → 전체 내보내기로 JSON 파일 저장
2
팀원에게 전달 → 팀원이 데이터 불러오기로 합치기

팀원 로그인

처음 접속 시 입력한 비밀번호가 팀 공유 코드 기준이 됩니다. 팀원 모두 동일한 비밀번호를 사용하세요.
